# Material for Robotaxi-Tracker/robotaxi-service-areas#13

- `*.png`: outlines of `main`, PR #13 and the robotaxi_stats trace, drawn over Waymo's 27 Oct 2026 help-center map, georeferenced against OpenStreetMap roads.
- `traces/*.geojson`: robotaxi_stats traces of Waymo's current help-center maps (https://support.google.com/waymo/answer/9059119), in this repo's boundary format. Traced from images, not exported from the app, so edges are approximate (typically 50–250 m). Feel free to use them in robotaxi-service-areas.
